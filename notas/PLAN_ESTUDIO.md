# Plan de Estudio y Preparación para Entrevistas

> [!TIP]
> Este archivo sirve como base para tu preparación técnica y se sincroniza automáticamente con el Centro de Mando offline y la PWA móvil.

---

## 1. Pitch Personal (Elevator Pitch)
- [ ] Practicar presentación personal en 60–90 segundos.
  - Quién soy y cuál es mi especialidad técnica.
  - Proyectos más destacados y tecnologías clave (React, Node, TypeScript, SQL).
  - Qué tipo de problemas me apasiona resolver y por qué me interesa la posición.

---

## 2. Fundamentos de Arquitectura & Backend
- [ ] **Diseño de APIs RESTful:**
  - Códigos de estado HTTP adecuados (200, 201, 204, 400, 401, 403, 404, 409, 429, 500).
  - Idempotencia (GET, PUT, DELETE) vs no-idempotencia (POST, PATCH).
  - Paginación por cursor vs paginación por offset.
- [ ] **Bases de datos:**
  - Índices en PostgreSQL (B-Tree, Hash, cuándo usarlos y cuándo no).
  - Transacciones y niveles de aislamiento (ACID).
  - Manejo de conexiones y connection pooling.

---

## 3. Frontend & Rendimiento Web
- [ ] Ciclo de vida y re-renderizados en React (useMemo, useCallback, React.memo).
- [ ] Estrategias de carga: Lazy loading, Code splitting, Web Workers.
- [ ] Manejo de estado global vs estado local del servidor (TanStack Query, Zustand).

---

## 4. Preguntas para los Entrevistadores
- ¿Cómo es el ciclo habitual de despliegue y release en su equipo?
- ¿Cuáles son los mayores desafíos técnicos u objetivos que el equipo busca resolver este trimestre?
- ¿Cómo miden el éxito de este rol durante los primeros 90 días?
